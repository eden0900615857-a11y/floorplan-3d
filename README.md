# floorplan-3d

上傳房屋平面圖，網頁自動辨識牆線並產生 3D 模型；之後延伸成室內裝修模擬（擺家具、換材質）。

## 目前進度
**階段 0：雛形**（`index.html`）
用瀏覽器直接開啟 `index.html` 即可使用（需連網載入 Three.js），不需要安裝或伺服器。

辨識流程：
1. 讀入圖片，縮到長邊 900 px。
2. 灰階化，用 Otsu 自動決定黑白門檻（可手動調整，也可反相處理藍圖）。
3. 形態學開運算：比「最小牆厚」細的線條（文字、尺寸線、家具、門弧）會被濾掉，只留下牆。
4. 把牆的像素合併成矩形，用 Three.js InstancedMesh 拉高成 3D 牆體。
5. 原圖貼在地板當底圖；使用者輸入圖面實際寬度（公尺）換算比例。

已知限制：斜牆與弧形牆會被切成很多小方塊；門窗目前只是牆上的缺口。

## 技術方向
- 第一版為純前端網頁，辨識在瀏覽器內執行，不需後端，可部署在 GitHub Pages。
- 辨識方式：影像處理（先支援黑白施工平面圖，再支援建商彩色格局圖）。
- 3D：Three.js。
