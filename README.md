# floorplan-3d

上傳房屋平面圖，網頁自動辨識牆線並產生 3D 模型；之後延伸成室內裝修模擬（擺家具、換材質）。

## 使用方式
用瀏覽器直接開啟 `index.html` 即可（需連網載入 Three.js），不需要安裝或伺服器。也可以開啟 GitHub Pages 當網站使用。

1. 上傳平面圖圖片（JPG、PNG），或按「載入範例」。
2. 調整「最小牆厚」等設定，直到藍色的牆和圖上的牆一致。
3. 切到「2D 校正」修正辨識錯的地方：
   - **選取**：點選牆後拖曳移動，拖曳兩端的方塊調整長度，Delete 刪除，可以直接修改牆厚。
   - **畫牆**：拖曳畫出漏掉的牆。接近水平或垂直時會自動拉直（按住 Alt 可畫斜牆），靠近其他牆的端點會自動接上。
   - **加門、加窗**：點在牆上加一扇門（0.9 公尺）或窗（1.2 公尺）。選取後可沿牆拖曳、修改寬度，門可以切換開門方向。
   - **比例尺**：點兩個點（例如尺寸標註的兩端），輸入實際長度，整張圖會照比例縮放。
   - 復原、重做：Ctrl+Z、Ctrl+Shift+Z（或 Ctrl+Y）。拖曳空白處平移，滾輪縮放。
4. 在「3D 檢視」旋轉、縮放查看。
5. 結果和手動修改會自動保存在瀏覽器；也可以「下載 JSON」存檔，之後用「開啟 JSON」繼續。

手動修改過之後，調整牆線辨識的設定不會直接覆蓋，會先詢問是否要重新辨識。

## 辨識流程
1. **偵測牆像素**（`js/detect.js`）：灰階化，用 Otsu 自動決定黑白門檻，再用形態學開運算濾掉比「最小牆厚」細的線條（文字、尺寸線、家具、門弧）。
2. **向量化**（`js/vectorize.js`）：沿每一列、每一欄找出連續的牆像素，歸成水平或垂直的帶狀牆，再合併同一條線上的小缺口。每面牆變成「中心線 + 厚度」的直線段。
3. **門窗辨識**（`js/openings.js`）：在牆與牆之間 0.5–2.5 公尺的缺口裡找圖例符號。缺口內有沿牆的細線是窗；缺口旁有四分之一圓的開門弧是門（同時判斷門軸位置與開門方向）；都沒有就當作開放通道。找到門窗時，缺口兩側的牆合併成一面牆，門窗掛在牆上。
4. **平面圖 JSON**（`js/plan.js`）：把線段換算成公尺，存成統一的資料格式（見 `docs/設計脈絡.md` 第 7 節）。
5. **2D 校正**（`js/edit.js` 編輯操作、`js/editor.js` 畫面）：所有修改都寫回同一份 JSON，可以復原。
6. **3D 場景**（`js/scene.js`）：只根據 JSON 產生牆體與地板。門的位置挖空到門高，窗戶保留窗台和上方的牆，中間放一片玻璃。

目前只支援水平、垂直的牆；斜牆和弧形牆會被略過，「向量化覆蓋率」會因此下降。門窗辨識依賴施工圖的標準圖例，拉門、折門等其他畫法還認不出來，可以在 2D 校正手動加上。
