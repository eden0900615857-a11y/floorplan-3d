# floorplan-3d

上傳房屋平面圖或施工圖 PDF，網頁自動辨識牆線並產生 3D 模型，再擺上家具、換地板與牆面顏色，模擬室內裝修。

## 使用方式
用瀏覽器直接開啟 `index.html` 即可（需連網載入 Three.js，開 PDF 時另外載入 pdf.js），不需要安裝或伺服器。也可以開啟 GitHub Pages 當網站使用。

1. 上傳平面圖圖片（JPG、PNG）或 CAD 輸出的 PDF 施工圖，或按「載入範例」（黑白施工圖）、「彩色範例」（建商彩色格局圖）。
   - **彩色格局圖**：上傳有顏色的圖片時會自動勾選「彩色格局圖」，把木紋、磁磚、家具插圖這些有顏色的地方當作背景，只把深灰或黑色的牆找出來，淺藍色長條當作窗。
   - **PDF**：會先顯示整張圖紙。在「選擇範圍」拖曳框出要辨識的那一層平面圖（不要框到面積表、圖框或其他樓層），填上圖名旁的比例（1/100 就填 100），按「辨識選取範圍」。之後可以回到「選擇範圍」改框其他樓層。
2. 圖片：調整「最小牆厚」等設定，直到藍色的牆和圖上的牆一致。PDF 直接讀取線條，不需要調整。
3. 切到「2D 校正」修正辨識錯的地方：
   - **選取**：點選牆後拖曳移動，拖曳兩端的方塊調整長度，Delete 刪除，可以直接修改牆厚。
   - **畫牆**：拖曳畫出漏掉的牆。接近水平或垂直時會自動拉直（按住 Alt 可畫斜牆），靠近其他牆的端點會自動接上。
   - **加門、加窗**：點在牆上加一扇門（0.9 公尺）或窗（1.2 公尺）。選取後可沿牆拖曳、修改寬度，門可以切換開門方向。
   - **房間**：點選房間可以改名。房間會依牆自動找出來，修改牆之後會重新計算，房名會保留。
   - **擺家具**：從選單選家具（客廳、臥室、餐廚、衛浴共 18 種，尺寸是常見的實際尺寸），點在圖上放下，按住不放可以直接拖到定位。粗線那一邊是家具的正面。選取家具後可以拖曳移動、按 R 或「旋轉 90°」轉向、修改寬和深，Delete 刪除。
   - **比例尺**：點兩個點（例如尺寸標註的兩端），輸入實際長度，整張圖會照比例縮放。
   - 復原、重做：Ctrl+Z、Ctrl+Shift+Z（或 Ctrl+Y）。拖曳空白處平移，滾輪縮放。
4. 在「3D 檢視」旋轉、縮放查看。
   - **地板材質**：在左側房間清單（或 2D 校正選取房間時）幫每個房間選地板，共 6 種：淺色、深色木地板，白色拋光石英磚、灰色磁磚、水泥粉光、白色大理石。
   - **裝修方案**：左側「裝修」可以「複製成新方案」或開「空白方案」，每個方案有自己的家具、地板和牆面顏色（牆和門窗共用），可以改名、刪除。3D 右上角的選單可以快速切換比較。
   - **材料用量**：左側「材料用量」列出目前方案的各種地板面積（含 10% 損耗的叫料量）、牆面油漆面積與公升數、家具清單，方便和師傅討論。
   - **匯出圖片**：3D 右上角「匯出圖片」把目前畫面存成 PNG。
   - **牆面顏色**：左側「裝修」選擇整間房子的牆面顏色（白色、暖白、奶茶灰、灰綠、霧藍、深灰）。
   - **走進房子**：按 3D 右上角的「走進房子」，從最大的房間開始以第一人稱走動。W A S D 或方向鍵移動（左右方向鍵轉身，A D 側移），Shift 加速，拖曳畫面轉頭，Esc 離開。手機用右下角的按鈕。不會穿牆，也不會穿過家具，門可以走過去。
5. 結果和手動修改會自動保存在瀏覽器；也可以「下載 JSON」存檔，之後用「開啟 JSON」繼續。

手動修改過之後，調整牆線辨識的設定不會直接覆蓋，會先詢問是否要重新辨識。

## 辨識流程（圖片）
1. **偵測牆像素**（`js/detect.js`）：灰階化（彩色格局圖會把彩度加到亮度上，有顏色的地方變成白色），用 Otsu 自動決定黑白門檻，再用形態學開運算濾掉比「最小牆厚」細的線條（文字、尺寸線、家具、門弧）。
2. **向量化**（`js/vectorize.js`）：沿每一列、每一欄找出連續的牆像素，歸成水平或垂直的帶狀牆，再合併同一條線上的小缺口。每面牆變成「中心線 + 厚度」的直線段。
3. **補外牆**（`js/vectorize.js`）：圖片裁到外牆、牆一路碰到圖片邊緣時，沿著邊緣補一面牆，讓房間能封閉。
4. **門窗辨識**（`js/openings.js`）：在牆與牆之間 0.5–2.5 公尺的缺口裡找圖例符號。缺口內缺口旁有四分之一圓的開門弧是門（先找門，因為門口常畫門檻線）；有沿牆的細線是窗（同時判斷門軸位置與開門方向）；都沒有就當作開放通道。找到門窗時，缺口兩側的牆合併成一面牆，門窗掛在牆上。
4. **平面圖 JSON**（`js/plan.js`）：把線段換算成公尺，存成統一的資料格式（見 `docs/設計脈絡.md` 第 7 節）。
5. **房間**（`js/rooms.js`）：把平面切成 5 公分的格子，畫上牆（門窗當作關閉），從外圍把屋外填滿，剩下被牆圍住的區域就是房間。面積是牆內淨面積，同時換算成坪（1 坪 = 3.3058 m²）。
6. **2D 校正**（`js/edit.js` 編輯操作、`js/editor.js` 畫面）：所有修改都寫回同一份 JSON，可以復原。
7. **3D 場景**（`js/scene.js`）：只根據 JSON 產生牆體與地板。門的位置挖空到門高，窗戶保留窗台和上方的牆，中間放一片玻璃。每個房間的地板照材質貼圖（`js/materials.js`，貼圖用程式畫，不需要下載圖檔）。
8. **家具**（`js/furniture.js`）：家具庫與每件家具的造型（幾個方塊組成，不需要下載模型檔），存在平面圖 JSON 的 `furniture`。
9. **裝修方案**（`js/schemes.js`）與**材料用量**（`js/quantities.js`）：方案存在平面圖 JSON 的 `schemes`，切換時把該方案的家具、地板、牆色套回平面圖。
10. **漫遊**（`js/walk.js`）：人當作半徑 20 公分的圓，碰到牆就沿牆滑開；門洞上方的牆不擋路，窗台和家具會擋。漫遊時加上天花板。

## 辨識流程（PDF 施工圖）
CAD 輸出的 PDF 裡每條線都有精確座標，所以不看像素，直接讀線條：
1. **讀線條**（`js/pdflines.js`、`js/pdfpick.js`）：用 pdf.js 取出框選範圍內的所有線段（含曲線），換成圖片的像素座標。比例由使用者填寫的 1:N 換算，不用另外量比例尺。
2. **找牆**（`js/linewalls.js`）：施工圖的牆畫成兩條平行細線。水平、垂直的線和另一側最近、距離 8–30 公分的平行線配對成牆，距離就是牆厚。太短的線（虛線的一小段、文字筆畫）不拿來配對；一串等距的平行線（樓梯踏階）不算牆；四邊都畫出來、接著牆的小矩形是柱子；牆端延伸到相接的牆或柱子中心，讓牆角確實接起來；和主結構不相連的零星片段拿掉。
3. **門**：四分之一圓的開門弧，圓心是門軸，弧的一端落在牆上。門洞兩側的牆接成一面，門掛在上面。
4. **窗**：牆的兩個牆面之間有兩條以上的平行細線（玻璃、窗框）。窗兩側都在房間裡的（隔間牆）會拿掉。
5. 之後的平面圖 JSON、房間、2D 校正與 3D 都和圖片相同。

彩色格局圖的牆要是實心的深色（深灰、黑色）；灰色或黑色的家具（電視、深色沙發）可能被當成牆，需要在 2D 校正刪掉。用一張真實的建商格局圖測試過：牆大致正確，餐桌椅的圓弧偶爾會被當成門，需要在 2D 校正刪掉；格局圖通常沒有標尺寸，請用「比例尺」量一段已知長度。

目前只支援水平、垂直的牆；斜牆和弧形牆會被略過，「向量化覆蓋率」會因此下降。門窗辨識依賴施工圖的標準圖例，拉門、折門等其他畫法還認不出來，可以在 2D 校正手動加上。PDF 辨識是用一份真實施工圖調出來的，其他事務所的畫法可能需要再調整；家具、廚具的平行線有時會被當成牆，需要在 2D 校正刪掉。

```
npm test
```
測試使用 Node 內建的測試工具，不需要安裝套件。
